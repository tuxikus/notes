# screaming snake case

`SCREAMING_SNAKE_CASE` is a naming convention where:

* All letters are **UPPERCASE**
* Words are separated using **underscores (`_`)**

## Examples

```rust
MAX_USERS
SECONDS_PER_MINUTE
DATABASE_URL
DEFAULT_TIMEOUT
MAX_RETRY_COUNT
```

For example:

```rust
const MAX_USERS: u32 = 1000;
const SECONDS_PER_MINUTE: u32 = 60;
```
